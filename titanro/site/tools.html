TitanRO builds the helpers players used to download into both game clients (Windows and web) and this site, the same for everyone. Each built-in below names the tool it replaces: once the built-in is out, that tool is not allowed. Helper panels open with Ctrl+H in game.

Not allowed at any time: bots, automated buying, client or packet edits that change what the client sends, and anything that shows what the game hides (hidden players, traps). Edited GRFs are replaced by the built-in views below.

Limits for everyone

  • Two characters online per TitanRO account, on any mix of clients; the launcher and the server both enforce it.
  • One character per account inside a WoE castle.
  • Item use: one item every 250 ms for everyone, by hand or with @autopot.
  • Market search: one query every 2 seconds; no alerts on new listings.
  • Auto-follow (Shift + right-click a character) walks only, and only on field maps.
